# dabus-next · 大巴Bus 个人站（Next.js 版）

基于《大巴设计规范 v1.0》实现的 Next.js 实际项目。纯静态导出，构建产物可直接部署到任何静态托管。

## 技术栈

- **Next.js 15**（App Router + TypeScript）
- **静态导出**（`output: "export"`）— 零服务端依赖，`out/` 目录扔哪都能跑
- **零 UI 依赖** — 样式全部来自规范 token（CSS 变量），不引 Tailwind / 组件库
- **内联 SVG IP 形象** — 大巴头像/全身像为矢量组件，任意缩放不糊

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发模式 http://localhost:3000
npm run serve      # 本地预览 out/ http://localhost:4173
```

> ⚠️ **本机 `npm run build` 会因环境安全代理报 EPERM**，正式构建请走《维护指南.md》第三节的
> "镜像 + env -i" 流程（已验证，42 秒出包）。改日常内容只需 `npm run dev` 预览，不受影响。

## 页面结构

| 路由 | 内容 | 布局模式 |
|---|---|---|
| `/` | 首页：Hero → 三条运营线路 → 深色到站广播 → 路线图时间线 → 黄底 CTA | 双栏不对称 / 三列卡片 / 全宽深色面板 / 中轴时间线 / 全宽品牌色面板 |
| `/about/` | 司机档案：车窗全身像 + 自介 + 发车计划 | 左右分栏 / 纵向站点流程线 |
| `/contact/` | 乘车指南：5 张车票式联系卡 | 车票网格 |

## 设计规范

所有视觉决策遵循 `../大巴设计规范.md`：

- 三色铁律：交通黄 `#FFC400`（60%）/ 柏油黑 `#1A1A1A`（30%）/ 信号绿 `#00C853`（10%）
- 暖底 `#fefcf6` / `#faf6eb`，标题衬线 + 正文无衬线，`clamp()` 流式字号
- 每 section 布局不同，最多 1~2 个品牌色面板，无无限循环动画
