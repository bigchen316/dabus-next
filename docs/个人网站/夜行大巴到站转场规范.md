# 夜行大巴到站转场规范

> 已确认方向：网站采用“夜行主角”叙事。每次进入正式站点页面时，由大巴把访客带到站，IP 随后下车，把页面交给访客。

## 故事节奏

1. **驶入**：夜色、路灯和道路虚线先建立移动感，大巴从画面左侧缓慢驶入。
2. **到站**：大巴在画面中段平稳刹停，站点线路 A → B → C 指向当前页面。
3. **下车**：车门打开，IP 从车门走出并挥手，文案提示“到站了”。
4. **交接**：夜色淡出，正式页面露出，访客开始浏览。

## 体验参数

- 适用范围：正式站点页面；`/design-options/*` 设计探索页不套用，保证方案比较不被干扰。
- 动效时长：约 3 秒，强调“慢慢开来、到站下车”的陪伴感。
- 交互出口：右下角提供“跳过到站动画”，不阻塞熟悉网站的回访者。
- 无障碍：检测 `prefers-reduced-motion` 时直接进入页面，不强制播放移动效果。
- 页面切换：站内切换正式页面时重新播放到站转场，形成连续的“换站”叙事。

## 视觉语汇

- 夜空：深紫黑作为舞台底色，点状星光只做轻微闪烁。
- 大巴：保留大巴 IP 的白色车身、黄色车灯与耳机识别点。
- IP：下车使用挥手姿态，动作是对访客的欢迎，不添加眼镜等非本人特征。
- 文案：短句、低声量，优先使用“下一站，到了。”“欢迎下车，慢慢看。”。

## 维护约定

转场组件位于 `components/ArrivalTransition.tsx`，动效样式位于 `app/globals.css` 的“夜行大巴到站转场”区块。调整时优先保持四段节奏、跳过按钮和 reduced-motion 支持完整。
