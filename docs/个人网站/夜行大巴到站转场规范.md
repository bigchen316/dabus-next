# 夜行大巴页面路线规范

> 已确认方向：网站采用“夜行主角”叙事。路线条常驻页面底部，小巴带着访客从 A 站驶向 C 站，IP 在终点下车并戴上头套。

## 故事节奏

1. **始发**：页面底部出现一条轻量夜行路线，车窗里是戴耳机的 IP 司机。
2. **行驶**：小巴从 A 站经过 B 站，持续存在但不遮挡正文，让路线成为浏览过程的陪伴线索。
3. **到站**：小巴驶向 C 站并停下，车门打开，挥手 IP 从车旁出现。
4. **收尾**：IP 戴上头套，路线停留在 C 站，访客可以继续阅读或收起路线条。

## 体验参数

- 适用范围：正式站点页面；`/design-options/*` 设计探索页不套用，保证方案比较不被干扰。
- 动效时长：约 12 秒，强调“慢慢开来、站站停”的陪伴感；到站后不消失。
- 交互出口：路线条右上角可以收起，也可以从右下角重新显示。
- 无障碍：检测 `prefers-reduced-motion` 时直接显示 C 站终点状态，不强制播放移动效果。
- 页面切换：站内切换正式页面时重新从 A 站发车；`/design-options/*` 设计探索页不套用。

## 视觉语汇

- 夜空：深紫黑作为路线条底色，使用轻微玻璃感，不抢正文视觉焦点。
- 大巴：保留大巴 IP 的白色车身、黄色车灯与耳机识别点。
- IP：车窗使用驾驶姿态，终点使用挥手姿态完成下车；不添加眼镜等非本人特征。
- 文案：短句、低声量，优先使用“跟着我，慢慢开。”“到站了，戴上头套。”。

## 维护约定

路线组件位于 `components/ArrivalTransition.tsx`，动效样式位于 `app/globals.css` 的“页面内常驻路线”区块。调整时优先保持 A → B → C 的路线顺序、终点下车状态、收起入口和 reduced-motion 支持完整。
