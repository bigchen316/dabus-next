# C 版：苹果式简洁页面与清爽手绘 IP

更新：2026-10-14。用户已确认 C 版，并授权全站更新与上线。

## 视觉

- 页面白 #FFFFFF，辅助面 #F5F5F7，正文 #1D1D1F，次要文字 #6E6E73。
- 黄色 #FFD233 来自大巴插图与当前导航标记，不再铺满品牌三色。
- 系统无衬线字体，不加载外部字体；短标题、大留白，正文阅读优先。
- 只有插图带手绘笔触；界面不用撕纸、车票边框、投影、渐变或玻璃。
- 主素材为 public/illustrations/daba-c-bus.png：二维人物、不戴眼镜、黄色小巴、黑猫。所有页面复用同一份素材。

## 页面

- 首页：单屏不可纵向滚动，中央手绘主角、阅读实测按钮、最新文章。桌面和手机均适配。
- 文章列表：只列真实文章，不使用设计图 B 中的占位文章或日期。
- 文章详情：窄列正文、清晰标题、可横向查看的对比表。历史文章内容保留，注明记录时间。
- 司机档案：手绘形象、自介、内容方向和联系方式入口。
- 乘车指南：真实邮箱直接链接，其他平台保留真实账号搜索说明，不伪造主页地址。
- 旧设计链接：统一 C 版外观与归档说明，旧素材、规范和代码历史可从项目记录找回。
- 404 页面：同一套视觉、明确返回首页入口。

## 行为

保留真实导航、文章及邮箱链接、键盘焦点与跳过导航。无入场、跳页、滚动、悬停、角色互动或循环动画。任何恢复动画的改动都需要用户重新确认。

## 素材生成

使用内置 image_gen，对用户选中的 C-IP主角.png 做透明背景提取。提示词：只提取中央二维手绘黄色小巴、挥手的无眼镜黑发人物、车顶黑猫和行李；保留原画角色身份、姿态、色彩和笔触；移除全部网页文字、导航、按钮、背景、底部配图；输出真实透明背景，保留完整车身与安全边距，不添加文字、水印、阴影或三维效果。

## 设计方法

延续 design-taste-frontend 公开版中的短标题、真实内容、主视觉集中、去装饰原则，使用 frontend-design 落地。旧 v1.1 规范作为历史记录保留，当前实现以本文件为准。
