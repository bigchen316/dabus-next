# 以后怎么把网站放上首页

最省事的方式：把项目的 HTML 文件夹、交互插图和目标网址发给助手，再说“加到首页产品栏”或“加到 AI skill 实测”。不用自己修改页面组件。

可以直接复制下面这段话：

> 把这个项目加到我的个人网站首页。项目在 E:\Claude code\dabus-next，内容清单是 content/home-cards.json。放进【产品 / AI skill 实测】分类，名称是【项目名称】，一句话介绍是【用途】，点击后打开【网址或 HTML 路径】。插图素材在【路径，没有就不放】。保持现有三列卡片和分类切换，在 preview/hero-turntable 分支修改，构建和链接检查通过后更新预览，不推 main。

## 想自己改时，只需要两个地方

1. 网站文件放进 `public/projects/项目英文名/`，入口叫 `index.html`，原来的图片、CSS、JS 一起放进去并保持相对路径。已经有线上网址的网站不用复制文件。
2. 在 `content/home-cards.json` 的 `products`（产品）或 `tests`（实测）数组里增加一项。

下面只是填写格式，不会自动出现在首页：

```json
{
  "id": "my-new-project",
  "title": "项目名称",
  "description": "用一句话说清楚这个网站能做什么。",
  "url": "/projects/my-new-project/index.html",
  "action": "打开项目 →"
}
```

`url` 也可以填完整的 `https://...` 网址。整张卡片都能点击，静态 HTML 使用普通链接直接打开。

暂时没有插图，就不填 `image`。普通封面可以额外填：

```json
"image": "/projects/my-new-project/cover.webp",
"imageAlt": "这张封面展示的内容"
```

需要鼠标响应的交互插图，等素材准备好后交给助手接入卡片预览；目前没有放演示插图，也没有伪造第三个项目。桌面每行最多三个，项目增加后自动排到下一行，手机自动改为一列。

## 更新预览

运行 `npm run build`，再运行 `node scripts/check-export-links.cjs`。通过后，只推送 `preview/hero-turntable` 分支，Vercel 会自动更新预览。生成首页公仔素材时，仍统一运行 `node scripts/make-home-images.cjs "E:\个人IP形象文件"`，不要手动替换生成帧。
