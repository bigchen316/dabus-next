# 大巴Bus 个人网站资料

本目录集中保存网站的维护资料。网站运行代码、依赖清单和 Next.js 配置仍保留在仓库根目录，便于本地开发和托管平台识别。

现状（2026-10-24）：首页整合杂志式横排大字、前景基础款 360° 转盘和底部信息带，保留产品、AI skill 实测、推荐、关于我、联系五个分区。转盘帧由统一素材脚本生成并居中，支持自动旋转、暂停、拖动和键盘控制；页内平滑滚动、内容页短淡入均尊重系统的减少动态效果设置。文章、司机档案、乘车指南仍用手绘插图。整合版在 `preview/hero-turntable` 分支预览，不直接推送 `main`。项目不设固定设计规范（已于 2026-10-22 删除，需要时可从 Git 历史恢复），改动不受旧规则限制。
