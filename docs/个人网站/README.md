# 大巴Bus 个人网站资料

本目录集中保存网站的设计与维护资料。网站运行代码、依赖清单和 Next.js 配置仍保留在仓库根目录，便于本地开发和托管平台识别。

当前网站采用 C 版苹果式简洁页面（2026-10-15）：角色身份统一，动作按内容选择；首页招手、档案背包、联系写信、文章阅读及电脑工作。正文和内容方向也有贴题配图，全部静态。旧 v1.1 规范、早期探索稿、动效契约和 `/design-options/` 归档页已于 2026-10-22 删除，需要时可从 Git 历史恢复。

维护时运行 `node scripts/check-ip-poses.cjs`，同时检查动作分配、重复使用、当前 IP、C 版样式与无动画要求。

- [维护指南](./维护指南.md)：日常编辑、预览与本机构建流程
- [部署指南](./部署指南.md)：GitHub 与 Vercel 部署说明
