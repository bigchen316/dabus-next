# 大巴Bus 个人网站资料

本目录集中保存网站的设计与维护资料。网站运行代码、依赖清单和 Next.js 配置仍保留在仓库根目录，便于本地开发和托管平台识别。

当前网站采用静态界面（2026-10-12）：所有装饰性互动与动画已移除，小巴/小猫只显示固定形象，正常链接和键盘焦点保留。下列动效资料仅作历史留档，不再应用。

维护时可运行 `node scripts/check-static-ui.cjs` 检查是否意外引入动画、悬停特效或角色事件处理。
