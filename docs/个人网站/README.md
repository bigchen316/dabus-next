# 大巴Bus 个人网站资料

本目录集中保存网站的维护资料。网站运行代码、依赖清单和 Next.js 配置仍保留在仓库根目录，便于本地开发和托管平台识别。

现状（2026-10-24）：首页为杂志式横排大字、前景基础款 360° 转盘和底部信息带。公仔只响应手动操作，使用穿过头部中心的竖轴与固定机位；所有素材仍由统一脚本生成。下方产品、AI skill 实测、推荐、关于我、联系五类内容在原地切换，桌面项目卡片一排三个，悬停轻微抬起。项目内容统一放在 `content/home-cards.json`，没有新增占位插图或虚构网站。文章、司机档案、乘车指南仍用手绘插图。整合版在 `preview/hero-turntable` 分支预览，不直接推送 `main`。项目不设固定设计规范（已于 2026-10-22 删除，需要时可从 Git 历史恢复），改动不受旧规则限制。
