# Oil UI Pro 三版方向草案

更新：2026-10-08  
状态：候选方案，尚未选定

## 共同任务

让第一次访问的人在首屏知道「大巴是谁、分享什么、下一步去哪」，并能顺着首页进入司机档案、首篇实测和乘车指南。三版都保留交通黄 `#FFC400`、柏油黑 `#1A1A1A`、信号绿 `#00C853`，以及无眼镜耳机 IP 形象。

## 方向 01：硬派站牌 / BOLD BUS STOP

- 北极星：像走到一块正在发车的城市站牌，信息先被看见，动作马上能发生。
- 首屏骨架：纵向路线栏 + 大标题 + 站牌式 IP 舞台，不使用常规左右双栏。
- 页面结构：发车牌列表 → 到站广播 → 纸质实测票据 → 站点页脚。
- 视觉：交通黄是画布，柏油黑负责结构，信号绿只做站点灯和行动反馈。
- 控件：硬边、直角、粗线；按下时产生短距离错位，像按钮被压进站牌。
- 适合：希望个人品牌更大胆、更容易被记住。

## 方向 02：公路编辑部 / ROAD JOURNAL

- 北极星：像翻开一本持续更新的个人杂志，先读一句观点，再沿栏目继续往下看。
- 首屏骨架：杂志跨页式双栏，IP 是纸面上的主视觉，标题承担最大视觉重量。
- 页面结构：栏目分栏 → 下一站广播 → 首篇实测专题 → 站点页脚。
- 视觉：暖白和奶油纸色做底，柏油黑做标题，信号绿画路线，黄色只标出重点。
- 控件：细线、低圆角、清楚的文字链接；悬停时通过留白和路线线条反馈。
- 适合：希望长期经营内容、文章和个人观点。

## 方向 03：夜间信号台 / NIGHT SIGNAL

- 北极星：像打开一台正在工作的内容控制台，看到信号、过程和下一条输出。
- 首屏骨架：左侧频道输入区 + 右侧实时监视器，内容本身组成控制台。
- 页面结构：频道监听列表 → 处理日志 → 归档文章 → 系统页脚。
- 视觉：深夜蓝黑作为工作台，信号绿表示状态，交通黄表示高优先级结论。
- 控件：等宽编号、细边框、状态灯和进度条；悬停时像日志行被唤醒。
- 适合：希望突出 AI 工具、实测和一点科技气质。

## 选择后更新

选定方向后，把该方向的北极星、字体关系、色彩比例、控件语法、动效和样板页面写入[大巴设计规范](./大巴设计规范.md)，再将它迁移到正式首页、司机档案和乘车指南。当前正式站继续沿用已完成的公路编辑部版本。
